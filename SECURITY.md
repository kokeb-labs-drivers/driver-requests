# Security policy

This repository follows the
[security policy of the kokeb-labs-drivers organisation](https://github.com/kokeb-labs-drivers/.github/blob/main/SECURITY.md).
Report a vulnerability privately, through a GitHub security advisory or by email to <kokeblabs@gmail.com>. Never
open a public issue for it, here or in a driver repository.

A weakness in this repository's own triage workflow (for example issue text that reaches a shell or changes
labels it should not) is in scope and is reported the same way.
